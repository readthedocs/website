About Read the Docs

We've been building and hosting documentation for open source projects since 2010. Read the Docs is open source and independent, run by a small team with help from our community.

Mission

Documentation should be part of every development workflow. We build the tools to write, build, and host your docs directly from your Git repository, so updating documentation is as simple as merging a pull request.

Scale

What started as a weekend project now hosts documentation for over 100,000 open source projects. Every month we serve over 250 million pageviews and run over 350,000 documentation builds.

Community

Read the Docs depends on users like you for development, support, and funding. Learn how to contribute in our documentation.

Hosting for the project is graciously provided by AWS.
