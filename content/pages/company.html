About Read the Docs

We've been building and hosting documentation for open source projects since 2010, and for companies since 2014. Read the Docs is run by a small team and mostly bootstrapped — companies paying for private documentation hosting are what fund the free community site.

Mission

Read the Docs was founded to improve documentation in the open source community. Our vision is to be the best place to host software documentation using a docs-as-code approach.

We build on top of Git, so your documentation ships the same way your code does.

Scale

What started as a weekend project now hosts documentation for over 100,000 open source projects. Every month we serve over 250 million pageviews and run over 350,000 documentation builds.

See how we run it, on infrastructure graciously provided by AWS.

Community

Read the Docs is open source and community supported. It depends on people like you contributing to development, support, and operations.

Learn how to contribute, and thanks to our community team who help us run the site.
