{# Funding #}
{{ section_header("How free hosting stays free", "We believe that having both paying customers and ethical advertising is the best way to create a sustainable platform for our users.") }}

Supported by EthicalAds

All documentation sites include a single non-tracking ad from EthicalAds. We don't track you, sell your data, or anything else. We simply show ads to users, based on the content of the pages you look at.

We also give 10% of our ad space to community projects, as our way of saying thanks to the open source community.

Funded by Read the Docs Business

Read the Docs is run by a small team and mostly bootstrapped — companies paying for private documentation hosting are what fund the free community site. This allows us to focus 100% on our users.

Learn about Read the Docs Business →

Running Read the Docs isn't free, and the site wouldn't be where it is today without generous support of our sponsors: AWS, Cloudflare, Elastic, and the Chan Zuckerberg Initiative.

{# FAQ #}
{{ section_header("Community FAQ") }}

Is it really free?

Yes. Open source documentation is always free on Read the Docs Community, supported by a single non-tracking ad on the documentation.

Can I host private documentation?

Read the Docs Community only supports public Git repositories, and all documentation is publicly accessible to the world. For private repositories and documentation that requires authentication, use Read the Docs Business.

What support is included?

Email support is included for issues with our platform. Read the Docs does not offer support for questions or problems with documentation tools or content. Learn how to get support →

How do builds compare to Read the Docs Business?

Read the Docs Community has less build time and fewer build resources (memory & CPU). See Choosing a platform for all the differences.
